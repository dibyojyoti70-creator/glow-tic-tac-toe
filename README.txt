Glow Tic-Tac-Toe
================

Files:
- index.html: complete browser game (HTML, CSS, JavaScript)

Test locally:
1. Extract this ZIP.
2. Double-click index.html to open it in a browser.

Publish with GitHub Pages:
1. Create a new GitHub repository.
2. Upload index.html (or upload the extracted files).
3. In repository Settings > Pages, select Deploy from a branch.
4. Choose the main branch and /(root), then Save.
5. Wait for GitHub Pages to publish the playable website URL.

Game includes:
- Friend mode (two players on one device)
- Computer mode with Easy, Medium, and Hard difficulty
- Score tracking, sound effects, and Play Again
